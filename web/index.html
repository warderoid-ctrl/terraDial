Install terraDial

Firmware for the terraPen control panel — the CrowPanel 1.28″ round display. Plug it in, click the button, done. Nothing to compile and nothing to install on your computer.

Your browser can't talk to USB devices. Use Chrome or Edge on a desktop — Safari, Firefox and every mobile browser lack the Web Serial support this needs. This page has to be served over HTTPS to reach the USB port.

What to expect

  1. Connect the panel to your computer with a USB-C data cable. Charge-only cables are the single most common reason the port doesn't appear.
  2. Click Connect and install and pick the panel from the list of serial ports.
  3. Choose Install terraDial. It erases and writes the whole chip, which takes a minute or two.
  4. When it's finished, the panel reboots into the dial.

Then set up Wi-Fi

Released firmware ships with no network baked in, so the first boot comes up unconnected. On the panel: Settings → Wi-Fi → Scan, pick your network and type the password with the knob. That's stored on the panel and survives later updates.

Updating later

You only need this page once. After the first install the panel updates itself over Wi-Fi — Settings → About → Check for updates — and no cable is involved. Come back here if a panel ever needs recovering.

If the port doesn't show up

  • Try a different USB-C cable, and a port directly on the computer rather than through a hub.
  • Hold the BOOT button, tap RESET, then release BOOT. That forces the download mode the installer needs when the automatic reset doesn't take.
  • Close anything else holding the port — a serial monitor, the Arduino IDE, pio device monitor.
